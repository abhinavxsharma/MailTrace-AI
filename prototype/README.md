# MAILTRACE AI Prototype

Browser-based simulation of the MAILTRACE AI investigation workflow.

## Included capabilities

- Gmail-style email ingestion simulation
- BEC, credential-phishing, and legitimate scenarios
- Forensic header and authentication analysis
- IP/domain/URL intelligence visualization
- Evidence-fused risk scoring
- Explainable AI evidence contribution view
- Interactive infrastructure and campaign relationship graph
- Architecture explorer for the MVP pipeline
- Raw headers and observed route inspection
- Forensic report export

## Run

Open `mailtrace_ai_advanced_xai.html` directly in a modern browser.

The prototype is intentionally self-contained and uses simulated evidence for the presentation workflow. Production integrations are described in the repository architecture and methodology documents.
